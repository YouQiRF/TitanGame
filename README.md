# Titan Slash

網頁 Boss Rush 原型。零遊戲引擎、零執行期相依套件，只有 TypeScript + Canvas 2D。

**▶ 立刻遊玩：https://youqirf.github.io/TitanGame/** （電腦鍵鼠、手機觸控皆可）

---

## 核心機制

一把刀，一條規則：**拉得越遠 → 傷害越高 → 體力消耗越大**。

長按進入子彈時間瞄準，放開就朝該方向位移斬擊。位移期間幾乎全程無敵——
這裡沒有翻滾鍵，**斬擊本身就是唯一的閃避手段**，於是每一次進攻都同時是一次防禦的賭注。
瞄準到一半把游標（或手指）收回來就能取消，不出刀也不耗體力。

兩個章節，兩種對局：

| 章節 | Boss | 對局重點 |
| --- | --- | --- |
| 一 | 石之守衛 | 打壞部位＝製造永久弱點，但牠也會因此更狂暴 |
| 二 | 傀儡師 | 穿越彈幕逼近本體，特殊傀儡可回體力但會延遲爆炸 |

## 操作

|  | 移動 | 瞄準／斬擊 |
| --- | --- | --- |
| 電腦 | `W A S D` | 按住滑鼠左鍵瞄準，放開斬擊 |
| 手機 | 左半螢幕虛擬搖桿 | 右半螢幕按住往目標方向拖，放開斬擊 |

手機請橫向持握（場地是 1100×820 的橫向競技場）。

## 開發

```bash
npm install
npm run dev           # 本機開發（http://localhost:5173）
npm run build         # 產出 dist/
npm run build:single  # 額外產出 TitanSlash.html —— 單一檔案，雙擊即可離線遊玩
```

## 專案結構

```
src/
  main.ts        場景管理 + 主迴圈（時間縮放、hitstop、繪製分層）
  tuning.ts      所有數值集中在這裡，調手感不用翻程式碼
  slash.ts       斬擊解算：距離 → 傷害 / 體力的唯一計算來源
  player.ts      玩家狀態機（idle / slash / dead）與無敵幀
  boss/          石之守衛、傀儡師
  core/          輸入（鍵鼠 + 觸控）、鏡頭、向量
  ui/            HUD、標題與結算畫面、觸控操作介面
```

幾個刻意的取捨：

- **數值與邏輯分離**：`tuning.ts` 是唯一的數值來源，手感迭代不需要動到邏輯。
- **傷害預覽與實際執行共用同一個函式**（`planSlash`），玩家看到的數字保證就是放手後會發生的事。
- **斬擊命中用完整軌跡線段判定**，不是每幀點對點，避免高速位移穿透 Boss。
- **輸入層抽象化**：鍵鼠與觸控共用同一組 API，遊戲邏輯不需要知道玩家用什麼裝置。
